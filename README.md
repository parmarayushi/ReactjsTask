# React Dashboard Task

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md) uses [Babel](https://babeljs.io/) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh
  "# ReactjsTask"

## Steps to clone the repository

1. Install Git.
2. Go to the repository you want to clone.
3. Click on Code button present in Green color.
4. Copy the repository URl.
5. Open Command prompt or terminal and go to the desired path or folder you want to clone the project.
6. Run the "git clone <repository-url>" command.
7. Go to the cloned repository.

Clone this project using the below command:
git clone -b develop https://github.com/parmarayushi/ReactjsTask
cd ReactjsTask

## Instructions for installing dependencies

1. Go to the develop branch.
2. Run the command "npm i" or "npm install" .

## Start JSON server

This project uses json-server to mock data from assets/json/db.json.
Run npx server --watch assets/json/db.json --port 3000

## Start the development server

npm run dev
